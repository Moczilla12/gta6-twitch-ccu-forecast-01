Forecasts GTA VI's launch-day Twitch concurrent viewers hour by hour (hours 2–24) from the first hour's print, by anchoring on the day-1 shapes of similar past big game launches and widening the quantiles for cross-launch spread.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
